Passive Web Recon & Public Intelligence

Use public indexes and archives to discover what is already known about an in-scope domain. These are separate, copyable commands — no long chained pipeline.

crt.sh Certificate Search

Public CT logs · Requires: curl + jq
$curl -fsSG 'https://crt.sh/' --data-urlencode 'q=%.{domain}' --data-urlencode 'output=json' | jq -r '.[].name_value' | tr ',' '\n' | sed 's/^\*\.//' | sort -u

Wayback CDX URLs

Archived URLs · Requires: curl
$curl -fsSG 'https://web.archive.org/cdx/search/cdx' --data-urlencode 'url=*.{domain}/*' --data-urlencode 'output=text' --data-urlencode 'fl=original' --data-urlencode 'collapse=urlkey' | sort -u

GAU Historical URLs

Wayback + Common Crawl + OTX + URLScan providers · Requires: gau
$gau --subs {domain} --threads 2 | sort -u > gau-urls.txt

waybackurls

Wayback Machine URLs · Requires: waybackurls
$printf '%s\n' '{domain}' | waybackurls | sort -u > wayback-urls.txt

URLScan Historical Results

Search public URLScan records · Requires: curl + jq + URLScan API key
$curl -fsSG 'https://urlscan.io/api/v1/search/' --data-urlencode 'q=domain:{domain}' --data-urlencode 'size=100' -H 'api-key: YOUR_URLSCAN_API_KEY' | jq -r '.results[]?.page.url' | sort -u

Common Crawl Index

Find archived URLs in Common Crawl · Requires: curl + jq
$INDEX=$(curl -fsS 'https://index.commoncrawl.org/collinfo.json' | jq -r '.[0].cdx-api') &amp;&amp; curl -fsSG "$INDEX" --data-urlencode 'url=*.{domain}/*' --data-urlencode 'output=json' | jq -r '.url' | sort -u

AlienVault OTX Passive DNS

Passive DNS observations · Requires: curl + jq
$curl -fsS 'https://otx.alienvault.com/api/v1/indicators/domain/{domain}/passive_dns' | jq -r '.passive_dns[]?.hostname' | sort -u

robots.txt Review

Read the site's published crawler rules · Requires: curl
$curl -fsSL 'https://{domain}/robots.txt'

Sitemap Review

Read published sitemap paths · Requires: curl
$curl -fsSL 'https://{domain}/sitemap.xml'

security.txt Check

Find the site's security contact policy · Requires: curl
$for path in /.well-known/security.txt /security.txt; do echo "### $path"; curl -fsSL "https://{domain}$path"; done

Basic HTTP Response Headers

Inspect response headers and redirects · Requires: curl
$curl -sSIL --max-redirs 5 'https://{domain}/'

TLS Certificate Summary

Inspect the presented TLS certificate · Requires: openssl
$printf '' | openssl s_client -connect '{domain}:443' -servername '{domain}' 2&gt;/dev/null | openssl x509 -noout -subject -issuer -dates -ext subjectAltName

Copy this query into Google; search results are not proof of exposure.
$site:{domain} (ext:env OR ext:log OR ext:bak OR ext:sql)

Search indexed hostnames; results may be incomplete or stale.
$site:*.{domain} -www

Copy into Bing; use only for authorized scope research.
$site:{domain} (filetype:pdf OR filetype:docx OR filetype:xlsx OR filetype:txt)

Complete Bug Bounty Workflow

1. Subfinder Basic

Quick subdomain enumeration with Subfinder
$ subfinder -d {domain} -silent -o subdomains.txt

2. Amass Deep Scan

Deep subdomain enumeration with Amass
$ amass enum -passive -d {domain} -o amass-passive.txt

3. Combine & Sort Subdomains

Combine and sort all found subdomains
$ cat subdomains.txt amass_results.txt | sort -u > all_subdomains.txt

4. DNS Records

Get all DNS records
$ dig {domain} A +noall +answer

5. WHOIS & SSL Info

Gather WHOIS and SSL certificate info
$ whois {domain} | tee whois.txt

6. HTTPX Live Check

Check for live subdomains and gather info
$ httpx -l all_subdomains.txt -silent -status-code -title -tech-detect -o httpx_results.txt

7. Dirsearch Scan

Directory and file enumeration
$ dirsearch -u 'https://{domain}/' -e php,html,txt -t 5 --delay 0.2 --format=simple -o dirsearch_results.txt

8. Nuclei Templates

Scan with Nuclei templates
$ nuclei -u 'https://{domain}' -severity info,low,medium -rl 2 -c 2 -o nuclei_results.txt

9. GF Pattern Matching

Search for vulnerable patterns
$ cat urls.txt | gf xss | sort -u > xss-candidates.txt

10. Katana Crawling

Smart web crawling
$ katana -u 'https://{domain}' -d 2 -jc -kf robotstxt,sitemapxml -rl 2 -silent -o katana_results.txt

11. Parameter Discovery

Discover hidden parameters
$ grep -E '\?.+=' katana_results.txt | sort -u > parameterized-urls.txt

12. CORS Check

Check for CORS misconfigurations
$ echo 'Use the maintained CORScanner installation instructions and run against one authorized URL at a time.'

13. Quick Technology Scan

Identify web technologies
$ whatweb 'https://{domain}' --no-errors

14. URL Manipulation

Replace query string values
$ cat params.txt | qsreplace "FUZZ" | tee fuzz_ready_urls.txt

15. Generate Report

Combine all results into a report
$ printf '# Bug Bounty Report: {domain}\n\n## Scope\n- Target: {domain}\n\n## Findings\n\n## Evidence\n\n## Remediation\n' > report.md
